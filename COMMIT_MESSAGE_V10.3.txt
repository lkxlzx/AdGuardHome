feat(dns-routing): 实现DNS路由后端API对接 (v10.3)

## 主要变更

### 数据结构扩展
- 扩展 FilterYAML 结构，添加 DNS 路由相关字段
  - DnsRouting: 标识为DNS路由过滤器
  - UpstreamGroup: 目标上游组ID
  - UpdateInterval: 更新间隔（分钟）
  - Priority: 匹配优先级

- 添加 CustomDomainRule 结构，支持自定义域名路由规则
  - Domain: 域名
  - MatchType: 匹配类型 (DOMAIN/DOMAIN-SUFFIX/DOMAIN-KEYWORD)
  - UpstreamGroup: 上游组ID
  - Enabled: 是否启用

### API 功能增强

#### 1. GET /control/filtering/status
- 新增返回字段 `dns_routing_filters`
- 自动将DNS路由规则从普通过滤器中分离

#### 2. POST /control/filtering/add_url
- 支持接收 DNS 路由相关字段
- 创建DNS路由规则时保存所有相关属性

#### 3. POST /control/filtering/set_url
- 支持更新 DNS 路由字段
- 修改上游组、优先级等属性时触发重启

#### 4. POST /control/filtering/remove_url
- 支持通过 dns_routing 标识删除DNS路由规则
- 精确匹配URL和dns_routing标志

#### 5. POST /control/filtering/refresh
- 支持刷新DNS路由过滤器
- 新增按URL刷新单个过滤器功能
- 实现 tryRefreshSingleFilter 函数

### 配置文件支持
- 在 dnsConfig 中添加 CustomDomainRules 字段
- 支持自定义域名规则的持久化存储
