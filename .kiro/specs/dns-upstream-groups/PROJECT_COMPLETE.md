#### 实现位置
- `internal/home/dns.go` (第48行) - ensureDefaultGroup 调用
- `internal/home/dns.go` (第258-268行) - 分组配置应用
- `internal/home/dns_upstream_groups.go` - ensureDefaultGroup 实现

#### 工作流程
```
系统启动 → ensureDefaultGroup() → 确保默认分组存在
         ↓
    initDNS() → newServerConfig() → 应用默认分组配置
         ↓
    DNS服务器使用分组配置进行解析
```


## 🔄 向后兼容性

### 配置文件兼容

#### 旧配置（仍然支持）
```yaml
dns:
  upstream_dns:
    - 8.8.8.8
    - 1.1.1.1
  bootstrap_dns:
    - 9.9.9.10
```

#### 新配置（推荐）
```yaml
dns:
  upstream_dns:
    - 8.8.8.8  # 作为后备配置
  bootstrap_dns:
    - 9.9.9.10
  
  upstream_groups:
    - id: "default-group"
      name: "默认"
      enabled: true
      is_default: true
      upstream_dns:
        - 223.6.6.6
        - 119.29.29.29
      bootstrap_dns:
        - 223.5.5.5
      created_at: "2024-01-01T00:00:00Z"
      updated_at: "2024-01-01T00:00:00Z"
```

### 配置优先级

```
有启用的默认分组 → 使用分组配置
否则 → 使用顶层配置（后备）
```
