# DNS路由功能 UI设计规划

## 概述

本文档详细规划DNS路由功能的用户界面设计，基于实际UI截图整理。

## 页面位置

DNS路由功能位于**过滤器(Filters)菜单**下，而不是DNS设置下。

## 页面结构

### 主页面布局

**页面标题**：DNS 路由
**副标题**：根据域名规则将 DNS 查询路由到不同的上游服务器组

页面包含两个主要卡片：
1. 规则路由（Rule Lists）- 从URL或文件导入的规则列表
2. 自定义域名规则（Custom Rules）- 手动添加的单个域名规则

## 卡片1：规则路由

### 1.1 卡片头部
- **搜索框**：配置域名分流规则，实现智能 DNS 解析

### 1.2 规则列表表格
表格列：
- **已启用**：复选框（勾选=启用，不勾选=禁用）
- **名称**：规则列表名称（如：CN）
- **清单网址**：规则文件的URL地址
- **DNS分组**：关联的上游DNS分组名称（如：国内）
- **规则数**：该列表包含的域名规则数量（如：3,706）
- **上次更新时间**：最后一次更新的时间戳（如：2025年12月3日 22:33）
- **操作**：三个图标按钮（从左到右）
  - 编辑按钮（铅笔图标）- 打开编辑对话框
  - 更新按钮（刷新图标）- 立即从URL重新下载规则
  - 删除按钮（垃圾桶图标）- 删除此规则列表

### 1.3 分页和操作
- **分页控制**：
  - 上一页/下一页按钮
  - 页码显示（页 1 / 1）
  - 每页行数选择下拉框（10行）
  
- **底部按钮**：
  - [添加规则] 绿色按钮
  - [检查更新] 蓝色按钮

## 对话框1：添加规则（规则列表）

### 对话框标题
**新增规则**

### 表单字段

1. **名称**
   - 文本输入框
   - 占位符：输入名称
   - 必填字段

2. **规则URL/文件路径**
   - 文本输入框
   - 占位符：请输入URL或列表的绝对路径
   - 说明文本：输入有效的规则 URL
   - 必填字段

3. **目标上游组**
   - 下拉选择框
   - 占位符：选择上游组
   - 说明文本：选择此规则匹配的域名应使用的 DNS 上游组
   - 必填字段

4. **定时更新间隔（分钟）**
   - 数字输入框
   - 默认值：0
   - 单位：分钟
   - 说明文本：设置规则自动更新的时间间隔，单位为分钟。设置为 0 表示不自动更新
   - 接受范围：0 或正整数（0 = 禁用自动更新）

5. **优先级**
   - 数字输入框
   - 默认值：0
   - 说明文本：设置规则匹配优先级，数字越小优先级越高。优先级高的规则会先被匹配

### 对话框按钮
- [取消] 灰色按钮
- [保存] 绿色按钮

## UI交互说明

### 规则列表操作
1. **启用/禁用规则**：点击"已启用"列的复选框即时生效
   - 勾选 = 启用该规则列表
   - 不勾选 = 禁用该规则列表（不参与DNS路由匹配）
2. **编辑规则**：点击操作栏的编辑按钮（铅笔图标）打开编辑对话框
3. **更新规则**：点击操作栏的更新按钮（刷新图标）立即从URL重新下载规则
4. **删除规则**：点击操作栏的删除按钮（垃圾桶图标），弹出确认对话框
5. **检查更新**：点击底部"检查更新"按钮，批量检查所有规则列表的更新

### 自定义规则操作
1. **添加规则**：点击底部"自定义规则"按钮打开添加对话框
2. **编辑规则**：点击操作栏的编辑按钮（铅笔图标）打开编辑对话框
3. **删除规则**：点击操作栏的删除按钮（垃圾桶图标），弹出确认对话框
4. **启用/禁用**：点击"已启用"列的复选框即时生效
   - 勾选 = 启用该自定义规则
   - 不勾选 = 禁用该自定义规则（不参与DNS路由匹配）

### 表单验证
1. **名称验证**：不能为空，不能重复
2. **URL验证**：必须是有效的HTTP/HTTPS URL或绝对文件路径
3. **域名验证**：根据匹配类型验证格式
4. **上游组验证**：必须选择一个已存在的分组
5. **数字验证**：优先级和更新间隔必须是非负整数

### 错误处理
1. **URL无法访问**：显示错误提示，保留旧规则
2. **规则格式错误**：显示警告，跳过无效行
3. **分组不存在**：提示用户先创建分组
4. **网络超时**：显示重试选项



## 样式和布局规范

### UI组件规范（必须与现有代码保持一致）

**按钮样式类名（参考上游分组实现）：**

1. **图标按钮**：
   - 编辑按钮：`btn btn-icon btn-outline-primary btn-sm`
   - 更新按钮：`btn btn-icon btn-outline-info btn-sm`（或使用refresh图标）
   - 删除按钮：`btn btn-icon btn-outline-secondary btn-sm`
   - 图标使用SVG sprite：`<svg className="icons icon12"><use xlinkHref="#edit" /></svg>`

2. **主要操作按钮**：
   - 添加规则：`btn btn-success btn-standard`
   - 检查更新：`btn btn-primary btn-standard`
   - 自定义规则：`btn btn-success btn-standard`

3. **对话框按钮**：
   - 保存/添加：`btn btn-success`
   - 取消：`btn btn-outline-secondary`

**表格样式：**
- 使用ReactTable组件
- 类名：`-striped -highlight card-table-overflow`
- 复选框：使用`<label className="checkbox">`结构
- 文本单元格：使用`logs__row`和`logs__text`类

**字体规范：**
- 默认字体：继承AdGuard Home全局字体设置
- 表格文本：使用`logs__text`类的字体样式
- 等宽字体（URL、域名）：`font-family: monospace; font-size: 13px;`
- 说明文本：`color: #6c757d; font-size: 0.875rem;`

**间距规范：**
- 按钮间距：`mr-2`（margin-right: 0.5rem）
- 卡片底部操作区：`card-actions`类
- 表单字段间距：使用Bootstrap标准间距

**颜色方案（Bootstrap主题）：**
- 成功/主要：`btn-success`（绿色）
- 信息/次要：`btn-primary`（蓝色）
- 编辑：`btn-outline-primary`（蓝色边框）
- 删除：`btn-outline-secondary`（灰色边框）
- 警告：`btn-outline-danger`（红色边框，如需要）

### 响应式设计
- 表格在小屏幕上应支持横向滚动
- 对话框最大宽度：600px（`modal-dialog max-width: 600px`）
- 按钮在小屏幕上堆叠排列

- 表单字段有明确的标签

## 重要说明

### 操作按钮详细说明

**规则路由表格的操作栏包含3个按钮（从左到右）：**
1. **编辑按钮**（铅笔图标）
   - 功能：打开编辑对话框，修改规则配置
   - 可编辑内容：名称、URL、目标上游组、更新间隔、优先级

2. **更新按钮**（刷新/循环图标）
   - 功能：立即从配置的URL重新下载规则列表
   - 行为：异步操作，显示加载状态
   - 成功后：更新"规则数"和"上次更新时间"

3. **删除按钮**（垃圾桶图标）
   - 功能：删除该规则列表
   - 行为：弹出确认对话框，确认后删除

**自定义域名规则表格的操作栏包含2个按钮：**
1. **编辑按钮**（铅笔图标）
   - 功能：打开编辑对话框，修改自定义规则
   - 可编辑内容：域名、匹配类型、上游组

2. **删除按钮**（垃圾桶图标）
   - 功能：删除该自定义规则
   - 行为：弹出确认对话框，确认后删除

### 启用/禁用功能说明

- **已启用列**：每行都有一个复选框
- **勾选状态**：
  - ✓ 勾选 = 规则已启用，参与DNS路由匹配
  - ☐ 未勾选 = 规则已禁用，不参与DNS路由匹配
- **即时生效**：点击复选框后立即保存并应用，无需额外确认
- **视觉反馈**：禁用的规则行可能显示为灰色或半透明

### 定时更新间隔说明

- **单位**：分钟
- **默认值**：0（表示不自动更新）
- **有效值**：
  - 0 = 禁用自动更新，仅手动更新
  - 正整数 = 每隔指定分钟数自动更新一次
- **常用值建议**：
  - 60 = 每小时更新
  - 360 = 每6小时更新
  - 1440 = 每天更新
- **更新行为**：
  - 后台自动执行
  - 失败时保留旧规则
  - 成功后更新"上次更新时间"
