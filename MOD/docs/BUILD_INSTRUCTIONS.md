## 如何测试前端 UI

### 1. 启动 AdGuard Home

```bash
# Windows
.\AdGuardHome.exe

# 或者指定配置文件
.\AdGuardHome.exe -c config.yaml
```

### 2. 访问 Web 界面

1. 打开浏览器访问: `http://localhost:3000`
2. 如果是首次运行，会进入安装向导
3. 完成安装后，登录管理界面

### 3. 查看 DNS 上游分组功能

1. 登录后，点击左侧菜单的 **"设置"**
2. 点击 **"DNS 设置"**
3. 在页面顶部可以看到 **"上游 DNS 服务器"** 部分
4. 这里就是新增的 DNS 上游分组功能

### 4. 测试功能

#### 查看分组列表
- 表格显示所有分组
- 包含：启用状态、分组名称、检测按钮、上游服务器地址、操作按钮

#### 添加新分组
1. 点击 **"添加DNS上游分组"** 按钮
2. 填写分组名称（例如：国内、海外）
3. 填写上游服务器列表（每行一个）
   ```
   8.8.8.8
   1.1.1.1
   https://dns.google/dns-query
   ```
4. 勾选 **"启用此分组"**（可选）
5. 勾选 **"设为默认分组"**（可选）
6. 点击 **"保存"**

#### 编辑分组
1. 点击分组行的 **编辑图标**（铅笔）
2. 修改分组信息
3. 点击 **"检测"** 测试连通性（可选）
4. 点击 **"保存"**

#### 删除分组
1. 点击分组行的 **删除图标**（垃圾桶）
2. 确认删除
3. 注意：不能删除默认分组

#### 启用/禁用分组
- 直接点击分组行的复选框即可切换状态

#### 复制分组
- 点击 **复制图标** 创建分组副本

### ⚠️ 后端 API 未实现

**重要**: 当前版本只包含前端 UI，后端 API 尚未实现。因此：

1. **所有操作都会失败**

## 下一步工作

### 后端 API 实现
要使功能完全可用，需要实现后端 API：

1. **数据模型** (任务 1-2)
   - 定义 Go 数据结构
   - 实现配置文件结构
   - 实现配置持久化

2. **HTTP API 端点** (任务 3)
   - `GET /control/dns/upstream_groups` - 获取所有分组
   - `POST /control/dns/upstream_groups` - 创建新分组
   - `PUT /control/dns/upstream_groups/:id` - 更新分组
   - `DELETE /control/dns/upstream_groups/:id` - 删除分组
   - `POST /control/dns/upstream_groups/:id/default` - 设置默认分组
   - `POST /control/dns/upstream_groups/:id/test` - 测试分组连通性

3. **分组管理器** (任务 2)
   - 实现 CRUD 操作
   - 实现默认分组逻辑
   - 实现并发安全

4. **DNS 解析器集成** (任务 4)
   - 集成分组管理器
   - 实现分组选择逻辑
   - 实现 DNS 解析流程

5. **测试** (任务 16-17)
   - 单元测试
   - 集成测试
   - E2E 测试

## 故障排除

### 问题：无法启动 AdGuard Home
**解决方案**: 
- 检查端口 3000 是否被占用
- 使用 `-p` 参数指定其他端口: `.\AdGuardHome.exe -p 8080`

### 问题：看不到 DNS 上游分组功能
**解决方案**:
- 确保已登录管理界面
- 进入"设置" → "DNS 设置"
- 功能在页面顶部

### 问题：操作失败显示错误
**解决方案**:
- 这是正常的，因为后端 API 尚未实现
- 可以查看浏览器控制台了解详细错误信息
- 主要用于测试 UI 展示和交互
