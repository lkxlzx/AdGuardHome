# 快速启动指南

## 🚀 立即测试前端 UI

### 1. 启动 AdGuard Home

```bash
.\AdGuardHome.exe
```

### 2. 打开浏览器

访问: http://localhost:3000

### 3. 完成安装向导

首次运行会进入安装向导：
1. 设置管理员账号和密码
2. 配置监听端口（默认即可）
3. 完成安装

### 4. 查看 DNS 上游分组功能

1. 登录管理界面
2. 点击左侧菜单 **"设置"**
3. 点击 **"DNS 设置"**
4. 查看 **"上游 DNS 服务器"** 卡片
5. 原有的文本域输入框已被分组表格替换

## 📸 UI 预览

### 上游 DNS 服务器卡片（已集成分组功能）
- 说明文本（带配置链接）
- 分组表格
  - 启用状态复选框
  - 分组名称（带默认标签）
  - 检测按钮
  - 上游服务器地址
  - 操作按钮（编辑、复制、删除）
- 分页控件
- 添加DNS上游分组按钮

### 添加/编辑对话框
- 分组名称输入框
- 上游服务器列表（多行输入，必填）
- 后备 DNS 服务器（多行输入，可选）
- Bootstrap DNS 服务器（多行输入，可选）
- 必填字段提示（红色）
- 帮助文本（灰色）
- 启用此分组复选框
- 设为默认分组复选框
- 取消/检测/保存按钮
