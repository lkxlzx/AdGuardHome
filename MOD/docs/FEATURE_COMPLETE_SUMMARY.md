### 后端

**文件**: `internal/home/dns_upstream_groups.go`

**API端点**:
- `GET /control/dns/upstream_groups` - 获取分组列表
- `POST /control/dns/upstream_groups` - 创建分组
- `PUT /control/dns/upstream_groups/{id}` - 更新分组
- `DELETE /control/dns/upstream_groups/{id}` - 删除分组
- `POST /control/dns/upstream_groups/{id}/default` - 设置默认分组
- `POST /control/dns/upstream_groups/{id}/test` - 测试分组

## 配置兼容性

### 向后兼容 ✅

**旧配置**（仍然支持）:
```yaml
dns:
  upstream_dns:
    - 8.8.8.8
  bootstrap_dns:
    - 9.9.9.10
```

**新配置**（推荐）:
```yaml
dns:
  upstream_dns:
    - 8.8.8.8  # 后备配置
  bootstrap_dns:
    - 9.9.9.10
  
  upstream_groups:
    - id: "group-1"
      name: "国内"
      enabled: true
      is_default: true
      upstream_dns:
        - 114.114.114.111
      fallback_dns:
        - 223.6.6.6
      bootstrap_dns:
        - 9.9.9.10
```

### 配置优先级

```
有启用的默认分组 → 使用分组配置
否则 → 使用顶层配置（后备）
```
