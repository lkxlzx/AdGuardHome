# 编译和测试指南

## 📋 前置条件

- Go 1.21+ 已安装
- Node.js 18+ 已安装
- npm 已安装

## 🔨 编译步骤

### 1. 编译前端

```bash
cd client
npm install
npm run build
cd ..
```

### 2. 编译后端

```bash
# Windows
go build -o AdGuardHome.exe

# Linux/Mac
go build -o AdGuardHome
```

### 3. 运行

```bash
# Windows
.\AdGuardHome.exe

# Linux/Mac
./AdGuardHome
```

## 🧪 测试步骤

### 1. 启动服务

启动AdGuard Home后，访问：
```
http://localhost:3000
```

### 2. 登录

使用配置的用户名和密码登录。

### 3. 访问DNS设置

导航到：设置 → DNS设置 → 上游DNS服务器

### 4. 测试功能

#### 测试1: 创建分组
1. 点击"添加DNS上游分组"按钮
2. 填写表单：
   - 分组名称：测试分组
   - 上游服务器列表：
     ```
     223.6.6.6
     119.29.29.29
     ```
   - 勾选"启用此分组"
   - 勾选"设为默认分组"
3. 点击"保存"
4. ✅ 验证：分组出现在列表中，显示"默认"标签

#### 测试2: 查看分组列表
1. 刷新页面
2. ✅ 验证：分组列表正确显示
3. ✅ 验证：默认分组有绿色"默认"标签

#### 测试3: 编辑分组
1. 点击分组的"编辑"按钮
2. 修改分组名称为"测试分组2"
3. 添加更多上游服务器
4. 点击"保存"
5. ✅ 验证：分组信息更新成功

#### 测试4: 创建第二个分组
1. 点击"添加DNS上游分组"
2. 填写表单：
   - 分组名称：海外DNS
   - 上游服务器列表：
     ```
     https://dns.google/dns-query
     https://cloudflare-dns.com/dns-query
     ```
   - 勾选"启用此分组"
   - 不勾选"设为默认分组"
3. 点击"保存"
4. ✅ 验证：新分组出现在列表中

#### 测试5: 设置默认分组
1. 找到"海外DNS"分组
2. 编辑该分组
3. 勾选"设为默认分组"
4. 点击"保存"
5. ✅ 验证：
   - "海外DNS"显示"默认"标签
   - 之前的默认分组不再显示"默认"标签

#### 测试6: 启用/禁用分组
1. 取消勾选某个分组的"已启用"复选框
2. ✅ 验证：分组状态更新成功

#### 测试7: 测试连通性
1. 点击分组的"检测"按钮
2. ✅ 验证：显示测试结果

#### 测试8: 尝试删除默认分组
1. 点击默认分组的"删除"按钮
2. 确认删除
3. ✅ 验证：显示错误提示"不能删除默认分组"

#### 测试9: 删除非默认分组
1. 点击非默认分组的"删除"按钮
2. 确认删除
3. ✅ 验证：分组从列表中消失

#### 测试10: 配置持久化
1. 重启AdGuard Home服务
2. 重新登录并访问DNS设置
3. ✅ 验证：所有分组配置都保留

#### 测试11: 验证YAML格式
1. 停止AdGuard Home
2. 打开配置文件 `AdGuardHome.yaml`
3. 查找 `upstream_groups` 部分
4. ✅ 验证：格式正确（块格式，不是流式格式）

```yaml
upstream_groups:
  - id: xxx
    name: 测试分组
    enabled: true
    is_default: true
    upstream_dns:
      - 223.6.6.6
      - 119.29.29.29
```

## 🐛 常见问题

### 问题1: 编译失败

**症状**: `go build` 报错

**解决方案**:
1. 检查Go版本：`go version`
2. 更新依赖：`go mod tidy`
3. 清理缓存：`go clean -cache`

### 问题2: 前端无法访问

**症状**: 浏览器显示404

**解决方案**:
1. 确保前端已编译：`cd client && npm run build`
2. 检查 `build` 目录是否存在
3. 重新编译后端

### 问题3: API请求失败

**症状**: 前端显示错误提示

**解决方案**:
1. 打开浏览器开发者工具
2. 查看Network标签
3. 检查API请求的状态码和响应
4. 查看后端日志

### 问题4: 配置文件格式错误

**症状**: YAML格式不正确

**解决方案**:
1. 检查 `gopkg.in/yaml.v3` 版本
2. 确保使用标准YAML标签
3. 参考 `bootstrap_dns` 字段的格式
