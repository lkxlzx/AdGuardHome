# DNS 上游分组功能 - 集成更新说明

## 更新概述

根据用户需求，已将 DNS 上游分组功能**融合到现有的"上游 DNS 服务器"卡片中**，**只替换了原来的文本域输入框**，改为分组表格的形式。**保留了所有其他功能**（负载均衡、后备 DNS 服务器、Bootstrap DNS 服务器、私人反向 DNS 服务器等）。

## 主要变更

### 1. 组件集成 ✅

**之前**: 使用大文本域输入框输入上游 DNS 服务器
**现在**: 使用分组表格管理上游 DNS 服务器
**保留**: 所有其他功能（负载均衡、后备 DNS、Bootstrap DNS、私人反向 DNS 等）

### 2. 文件变更

#### 新增的文件
1. **`client/src/components/Settings/Dns/Upstream/FormWithGroups.tsx`**
   - 新的表单组件
   - 将原有的文本域替换为分组表格
   - 保留所有其他表单字段和功能

#### 修改的文件
1. **`client/src/components/Settings/Dns/Upstream/index.tsx`**
   - 使用新的 FormWithGroups 组件
   - 保留了卡片标题"上游 DNS 服务器"
   - 保留了所有配置提交逻辑

2. **`client/src/components/Settings/Dns/UpstreamGroups/index.tsx`**
   - 导出 GroupList 和 GroupModal 供 Upstream 使用
