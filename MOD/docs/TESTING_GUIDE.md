# DNS上游分组功能测试指南

## 🔧 已修复的问题

### 1. 测试功能死锁 ✅
**问题**: 测试分组时发生死锁  
**原因**: 持有config锁的同时调用HTTP handler  
**解决**: 在调用HTTP handler前复制数据并释放锁

### 2. 默认分组编辑按钮 ✅
**问题**: 默认分组缺少编辑按钮  
**原因**: 可能是浏览器缓存了旧的JavaScript  
**解决**: 重新构建前端并清除浏览器缓存

## 🐛 故障排查

### 问题: 编辑按钮不显示

**可能原因**:
1. 浏览器缓存了旧的JavaScript
2. 前端没有重新构建
3. 后端没有重新编译

**解决方法**:
```bash
# 1. 重新构建前端
cd client
npm run build-prod
cd ..

# 2. 重新编译后端
go build -o AdGuardHome.exe

# 3. 清除浏览器缓存
# 按 Ctrl + Shift + Delete

# 4. 强制刷新页面
# 按 Ctrl + F5
```

---

### 问题: 测试功能卡死

**可能原因**:
1. 死锁（已修复）
2. 上游服务器无响应
3. 网络超时

**解决方法**:
1. 检查上游服务器是否可达
2. 检查防火墙设置
3. 查看服务器日志

---

### 问题: 设置默认分组后DNS请求没有切换

**可能原因**:
1. DNS服务器没有重新配置
2. 配置文件没有正确保存
3. 浏览器缓存了DNS结果

**解决方法**:
1. 重启AdGuardHome服务
2. 清除DNS缓存:
   ```bash
   # Windows
   ipconfig /flushdns
   
   # Linux
   sudo systemd-resolve --flush-caches
   
   # Mac
   sudo dscacheutil -flushcache
   ```
3. 检查配置文件 `AdGuardHome.yaml`
