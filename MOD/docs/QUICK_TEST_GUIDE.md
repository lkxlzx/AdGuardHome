# 快速测试指南

## 🚀 启动AdGuard Home

```bash
.\AdGuardHome.exe
```

## 🌐 访问界面

打开浏览器访问：
```
http://localhost:3000
```

## 🔐 登录

使用配置文件中的用户名和密码登录。

## 📋 快速测试清单

### 1. 访问DNS设置页面
1. 点击左侧菜单 "设置"
2. 点击 "DNS设置"
3. 找到 "上游DNS服务器" 部分

### 2. 查看分组列表
- ✅ 应该看到一个表格（可能为空）
- ✅ 应该看到 "添加DNS上游分组" 按钮

### 3. 创建第一个分组
1. 点击 "添加DNS上游分组"
2. 填写表单：
   - 分组名称：`测试分组`
   - 上游服务器列表：
     ```
     223.6.6.6
     119.29.29.29
     ```
   - ✅ 勾选 "启用此分组"
   - ✅ 勾选 "设为默认分组"
3. 点击 "保存"
4. ✅ 验证：分组出现在列表中，显示绿色"默认"标签

### 4. 编辑分组
1. 点击分组的 "编辑" 按钮（铅笔图标）
2. 修改分组名称为 `测试分组-已修改`
3. 点击 "保存"
4. ✅ 验证：分组名称已更新

### 5. 创建第二个分组
1. 点击 "添加DNS上游分组"
2. 填写表单：
   - 分组名称：`海外DNS`
   - 上游服务器列表：
     ```
     https://dns.google/dns-query
     8.8.8.8
     ```
   - ✅ 勾选 "启用此分组"
   - ⬜ 不勾选 "设为默认分组"
3. 点击 "保存"
4. ✅ 验证：新分组出现在列表中

### 6. 测试连通性
1. 点击任一分组的 "检测" 按钮
2. ✅ 验证：显示测试结果（成功/失败、响应时间）

### 7. 设置默认分组
1. 编辑 "海外DNS" 分组
2. ✅ 勾选 "设为默认分组"
3. 点击 "保存"
4. ✅ 验证：
   - "海外DNS" 显示 "默认" 标签
   - 之前的默认分组不再显示 "默认" 标签

### 8. 尝试删除默认分组
1. 点击默认分组的 "删除" 按钮（垃圾桶图标）
2. 确认删除
3. ✅ 验证：显示错误提示 "不能删除默认分组"

### 9. 删除非默认分组
1. 点击非默认分组的 "删除" 按钮
2. 确认删除
3. ✅ 验证：分组从列表中消失

### 10. 配置持久化测试
1. 停止AdGuard Home（Ctrl+C）
2. 重新启动：`.\AdGuardHome.exe`
3. 重新登录并访问DNS设置
4. ✅ 验证：所有分组配置都保留

## 🐛 常见问题

### 问题1: 无法访问界面
**解决方案**: 
- 检查AdGuard Home是否正在运行
- 检查端口3000是否被占用
- 尝试访问 `http://127.0.0.1:3000`

### 问题2: 无法登录
**解决方案**:
- 检查配置文件中的用户名和密码
- 查看 `AdGuardHome.yaml` 中的 `users` 部分

### 问题3: 看不到分组列表
**解决方案**:
- 打开浏览器开发者工具（F12）
- 查看Console标签是否有错误
- 查看Network标签，检查API请求是否成功

### 问题4: 创建分组失败
**解决方案**:
- 检查表单验证错误提示
- 确保分组名称不为空
- 确保至少有一个上游服务器
- 查看后端日志
